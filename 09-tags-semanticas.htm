Tags Semanticas em HTML 5

As tags semanticas são elementos html que descrevem claramente o significado do conteudo que elas envolvem. Elas ajudam a melhorar a acessibilidade, a SEO e a estrura do documento. Aqui estão algumas dos principais tags semanticas:

  • <header>: Define um cabeçalho de um documento com seção.

  • <nav>: Define um conjunto de links de navegação.

  • <main>: Define o conteudo principal do documento.

  • <section>: Define um seção generica de um documento.

  • <article>: Define um conteudo independente e auto-contido, como um artigo de blog ou noticia.

  • <aside>: Define um conteudo relacionado, mas separado do conteudo principal, como uma barra lateral.

  • <footer>: Define o rodapé de um documento ou seção.

Usar essas tags semanticas ajuda os motores de busca a entender melhor o conteudo do seu site e melhora a experiencia do usuario, especialmente para aqueles que utilizam leitores da tela.
